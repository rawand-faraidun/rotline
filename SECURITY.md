# Security

Found a security problem in Rotline (the game, the website or the servers)? Please report it privately
through **[GitHub's private vulnerability reporting](https://github.com/rawand-faraidun/rotline/security/advisories/new)**
rather than in a public issue. Include what you found, how to reproduce it, and what it could affect.

Cheats and exploits in the game count too: the server is meant to be the only authority on what
happens in a match.
